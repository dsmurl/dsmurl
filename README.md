# Samuel Bagot

Full-stack and platform engineer in Austin, TX. I build TypeScript monorepos end to end — React
front ends, Node/Bun APIs, a typed database layer, and the AWS infrastructure under all of it,
defined in code. I like the parts other people skip: the deploy story, the docs, and the seams that
make a codebase easy for the next person to pick up.

On GitHub since 2012, and writing code since a QBasic
[Mastermind](https://github.com/dsmurl/mastermind) in 1992.

## What I'm working on

A reusable Nx monorepo platform — React + Vite web app, Express/TypeScript API, Drizzle ORM over
SQLite and Turso, Supabase auth, Stripe payments, and Pulumi provisioning the AWS side. Most of that
work lives in private repos, so the public pins below are the parts I can show.

Lately I've also been building my own [Claude Code](https://claude.com/claude-code) tooling —
a plugin marketplace with skills for docs auditing, test conventions, and turning meeting
transcripts into scoped project work.
